🥁 Harsha Drumkit
Welcome to Harsha Drumkit — a fun and interactive virtual drum kit built with HTML, CSS, and JavaScript! Whether you're a music enthusiast or just want to have fun tapping away on your keyboard, this project lets you unleash your inner drummer right from your browser.

🔗 Live Demo: harshavardhan-github.github.io/harshaDrumkit

🎵 Features
🎹 Keyboard-controlled Drumkit – Use specific keys to play different drum sounds.

✨ Visual Feedback – Each key press is highlighted with smooth animations.

🎧 Authentic Drum Sounds – Crisp audio for a real drumming experience.

💻 Responsive Design – Works seamlessly across desktops, tablets, and mobile devices.

🧠 Simple & Clean Code – Beginner-friendly JavaScript implementation.

⌨️ How to Use
Just open the live demo and:

Tap the keys on your keyboard (W, A, S, D, J, K, L)

Each key triggers a different drum sound

Enjoy drumming with animated key effects!

🛠️ Built With
HTML5 – Structure and layout

CSS3 – Styling and animations

JavaScript (Vanilla) – Event handling and audio playback
